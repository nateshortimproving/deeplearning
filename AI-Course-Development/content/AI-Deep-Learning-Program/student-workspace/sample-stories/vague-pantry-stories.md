# Sample Epic: Vague Pantry Stories (Bad Example)

> **Demo file** — intentionally vague. This is what poor-quality stories look like: plausible-sounding but untestable, missing acceptance criteria, no edge cases, and no clear definition of "done." Use this as the "before" contrast in the good/bad/AI-generated demo in Session 1.

---

## Epic: Pantry Management

### Story 1: Manage pantry items

As a user, I want to manage my pantry items so that I can keep track of things.

**Acceptance Criteria:**
- The user can add items
- The user can remove items
- The system should be user-friendly

### Story 2: Search

As a user, I want to search my pantry so that I can find things.

**Acceptance Criteria:**
- The search should work
- Results should be relevant

### Story 3: Notifications

As a user, I want to be notified about my pantry so that I don't forget things.

**Acceptance Criteria:**
- The system sends notifications when appropriate
- Notifications are configurable

### Story 4: Shopping list

As a user, I want a shopping list so that I can buy things.

**Acceptance Criteria:**
- The app creates a shopping list
- The user can edit the list

### Story 5: Barcode scanning

As a user, I want to scan barcodes so that adding items is faster.

**Acceptance Criteria:**
- The app can scan barcodes
- Scanned items are added to the pantry

# Harness Specifications

This directory is where custom harness specifications would be committed in a future Stage 4 Deep Learning Program.

In the current DLP (Stage 3), custom harnesses are demonstrated by the instructor in Session 6 but are not built by participants. Building a custom harness — a Python program that orchestrates multi-step workflows with API calls, evaluation at each step, and adversarial agents — is the work of Stage 4 (Workflow), which requires team coordination, IT infrastructure, and ~10x the effort of Stage 3.

See the Improving Intelligence Operating System (IIOS) stage framework for details on Stage 3 vs Stage 4.

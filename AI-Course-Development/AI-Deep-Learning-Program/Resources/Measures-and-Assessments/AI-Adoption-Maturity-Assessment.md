# AI Adoption Maturity Assessment

*Reference page — Deep Learning Program (DLP)*

---

## What This Is

The **AI Adoption Maturity Assessment** is the primary participant assessment instrument for the DLP. It is a 21-question, 7-dimension instrument that measures participant progression from Basic Prompting through DLP Completion.

The full assessment is maintained as a separate document. This page is a reference pointer — do not administer the assessment from this file.

---

## Structure

- **21 questions** organized across **7 dimensions**
- Each question is rated on a scale; dimension averages roll up to an overall maturity profile
- **DLP Completion indicator:** Dimensions 1–4 scoring consistently at 3.0+ averages

### Dimension Focus Areas

The seven dimensions measure participant maturity across the v2 progression:

1. **Skill Craft** — Can the participant write skills using RTCC structure and the skill file format?
2. **Evaluation Criteria (EC) Discipline** — Does the participant write EC before building and iterate against them?
3. **Python Evaluation** — Can the participant build and run Python evaluation scripts with LLM judges to measure skill output quality?
4. **Iteration** — Does the participant iterate on skills based on evaluation evidence, with documented hypotheses and results?
5. **Adversarial Thinking** — Can the participant build adversarial agents that find problems the evaluation script didn't catch?
6. **Adoption** — Has the participant changed their default behavior to use skills as the first tool, not the fallback?
7. **Custom Harness Awareness** — Does the participant understand what a custom harness is and how it composes skills into multi-step workflows? (Demoed in Session 6; building one is a future Stage 4 program.)

## Who Administers It

The Embedded Engineer is responsible for ensuring participants complete the assessment at each administration point. Results are reviewed jointly by the Embedded Engineer and Trainer, and summarized for the Account Manager / Executive Coach for the Week 7 and Week 12 executive sponsor touchpoints.
